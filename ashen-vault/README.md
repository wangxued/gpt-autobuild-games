# 烬墟：山河异闻录

东方志怪题材的像素风动作 Roguelite 网页游戏。当前版本以原生 JavaScript 模块和 Canvas 实现，可直接由 GitHub Pages 静态托管，无需构建步骤。

## 本地运行

由于浏览器 ES Module 的安全限制，请通过本地 HTTP 服务打开：

```bash
cd ashen-vault
python3 -m http.server 8080
```

访问 http://localhost:8080。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动 |
| J / Space | 近身斩击 |
| K | 五雷敕令（范围符火） |
| Shift | 朝面向方向闪避 |
| Q | 使用回春丹 |
| P | 暂停 |

触屏设备可使用画面下方的方向键和动作按钮。

## 项目结构

- `src/main.js`：游戏循环、输入、战斗、敌人行为与 Canvas 渲染
- `src/dungeon.js`：房间生成、走廊连接和地形查询
- `src/systems.js`：角色成长、法器选择与本地存档
- `src/data.js`：章节、敌人与法器数据
- `styles.css`：中文界面与响应式布局

## 当前玩法

- 三卷章节主题，按层数推进
- 程序化房间与走廊地牢
- 尸傀、山魈、纸人与镇陵兽
- 近战、范围符火、闪避、药品
- 修为升级、法器选择、宝匣奖励
- 浏览器本地存档与继续行旅

## 说明

本项目为持续迭代中的独立游戏原型。美术目前由 Canvas 绘制的像素图形构成，后续可替换为独立精灵图与动画资源。
